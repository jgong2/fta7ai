Pillar 1 · LangGraph

State graph + 一道道 gate

把审核流程写成状态图（节点 + 连线 + 回环）。每条判据过一道 gate：LLM 建议，代码裁决。

Ingest 读入工厂文件 → 片段，每段带出处
↓
Criteria 判据匹配条款 × 工艺，精确查判据表
↓
Evaluate · 唯一的 LLM 节点读证据、给建议判定 + 引文
↓
Exit Gate 出口闸确定性代码：引文核对、五态判定（含「待现场确认」）
↓
Report 报告每个字都能追到原文页码
↺ Loop：专家改判 → 记一条样本 → 进 eval 集 → 再优化
Pillar 2 · Multi-agent · Multi-model

高端模型做判断，低成本模型跑批量

Claude 这类 frontier model 负责拆任务、定标准、终审；DeepSeek、通义千问 Qwen 跑大批量、低难度的活。按 cost × difficulty 路由，模型随时可换，调度层是我们自己的。

Pillar 3 · DSPy

让系统自己调 prompt，越用越准

DSPy 把 prompt 当成可训练的参数：给它一个评分函数（eval function）和一批专家改判过的样本，它自动找出更好的写法。老师傅每改一次判断，系统就多一条最值钱的 training data。

→ 漏掉真问题重罚；证据不足时老实说「待现场确认」加分。
