# FTA — Supplier Quality Consulting

Source code for **[fta7ai.com](https://fta7ai.com)**, the website of FTA, a supplier quality consulting business.

FTA puts eyes on your suppliers: on-site supplier audits, supplier assessments, and CAPA / SCAR closure, backed by **SAA, the Supplier Audit Agent**, an AI assistant that turns audit documents into defensible findings.

## What's here

| Path | Contents |
|---|---|
| `index.html` | The main English site |
| `cn/` | Chinese version of the site |
| `videos/` | Video assets used on the site |
| `CNAME` | Custom domain (`fta7ai.com`) for GitHub Pages |
| `DEPLOY.md` | How to publish and roll back the site |

## How it's published

The site is a static page served by **GitHub Pages** from the `main` branch. Any change pushed to `main` goes live on fta7ai.com. See `DEPLOY.md` for go-live and rollback steps.
